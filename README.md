# note-line-poster

LINE にネタを送るだけで、AI が SEO を意識した記事に仕上げて **note へ投稿**します。
画像を送って「ここに入れて」と伝えると、記事の指定した位置に入ります。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/e-pei/note-line-poster-template)

## はじめに読むもの

### 👉 **[セットアップ手順書をひらく](https://claude.ai/code/artifact/050c5115-c2ee-4314-bca4-3db0133919f2)**

押すとそのまま読めます。上から順に進めれば動きます。所要は **1時間ちょっと**。
**黒い画面（ターミナル）は一度も出てきません。**

> このリポジトリの docs/setup-guide.html は同じものの控えです。
> GitHub 上で開くとコードとして表示されるので、**上のリンクからお読みください。**

## できること

- LINE でネタを送ると、AI が記事を書く（キーワード設計 → 構成 → 本文 → タイトルの4段階）
- 画像を送って、記事のどこに入れるか指示できる
- 見出し画像（サムネイル）も設定できる
- LINE 上でプレビューを見て、**修正 → 公開**まで進める
- 公開した記事を、あとから**同じURLのまま更新**できる
- 自分の言い回しや決まりごとを「ナレッジ」として溜めると、記事に反映される
- 必要なら、AI が **Webで調べて出典つき**で書く／見出しの下に **AI の挿絵**を入れる、も選べます
  （どちらも最初はオフ。LINE の「AI設定」からオンにします）

## 動かすのに必要なもの

| | 何のために | 費用 |
|---|---|---|
| LINE公式アカウント | ネタを送る入口 | 無料プランで始められます |
| note のアカウント | 記事の投稿先 | 無料 |
| OpenAI の API キー | 記事を書く・調べる・画像を作る | **前払い**（最低5ドル）。使った分だけ |
| Cloudflare のアカウント | システムを動かす場所 | 無料の範囲で足ります |
| GitHub のアカウント | 置き場所として使う | 無料 |

★用意していただく AI のキーは **OpenAI の1つだけ**です。platform.openai.com で発行します。
ChatGPT（Plus など）の月額プランとは別物で、API 用の前払いクレジットが必要です。
**自動チャージはオフのまま**をおすすめします（前払いの残高が、使いすぎの歯止めになります）。

費用の目安（どれも目安です。実際の額は OpenAI の画面でご確認ください）:
記事1本 約20〜30円／Webで調べると＋約3〜11円／AI の画像1枚 約4〜5円

## 大事なこと

- **あなたの環境は、あなたのものです。** ログイン情報も記事も、すべてあなたの
  Cloudflare アカウントの中に入ります。開発元には届きません
- note には公式の投稿APIがありません。**非公式の経路を使っています。**
  note の仕様変更で動かなくなる可能性があります
- 投稿は**あなたが LINE で「公開する」を押したときだけ**行われます。勝手には出ません
- 記事の材料（ネタ・ナレッジ・画像の指示）は、文章や画像を作るために **OpenAI に送られます**
- AI の文章・調べた内容・画像は、正しさや実物との一致を保証できません。**公開する前に必ず目で確かめてください**

## 自動更新について

手順書の「自動更新をオンにする」を済ませると、提供元が配った最新版を**毎日1回、自動で取り込みます**
（このリポジトリの GitHub Actions が動きます）。

- 取り込む前に検査をして、通ったときだけ入れます。落ちたときは**何も変えず**、このリポジトリに Issue が立ちます
- **ファイルを自分で書き換えた場合は、上書きせずに自動更新が止まります**（書き換えた内容を消さないため）
- 止めたいときは、このリポジトリの直下に `.sync-pin` という名前のファイル（中身は空で可）を作ってください。
  Actions の画面でワークフローを無効にしても止まります
