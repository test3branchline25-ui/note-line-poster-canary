note-line-poster / 初回セットアップ

ゼロから通しで
組み上げる手順

新しいメールアドレスを1つ用意して、LINE公式アカウントから note への自動投稿が 動きだすところまで。この手順で作る環境は、使う人ひとり専用です。 チェックを付けながら進めてください。途中で閉じても、次に開いたときに続きから再開できます。

所要 約 89 分
費用 OpenAI のみ前払い
用意するもの パソコンの Chrome とスマホの LINE
手でやる

アカウントを作る・本人としてログインする・鍵を発行する。この3つには、どのサービスも API を用意していません。意図的に閉じている部分なので、迂回しません。

自動でやる

ボタンを押すと、あとは待つだけの作業です。入力も操作もありません。

かかるお金

サービス費用
LINE公式アカウント無料（コミュニケーションプラン）。 システムからの通知が月200通まで。 使い切っても自動で課金はされません（届かなくなるだけです）
note無料
OpenAI前払い。クレジットの購入が必要です（最低5ドル。使った分だけ減ります）
Cloudflare無料の範囲で足ります
GitHub無料
「完全に0円」ではありません

OpenAI だけは前払いです。記事を書かせるたびに少しずつ減ります。 用意していただく AI のキーは OpenAI の1つだけです （文章を書く・Webで調べる・画像を作る、のすべてに使います）。 ★ChatGPT（Plus など）の月額プランとは別物で、API 用の前払いクレジットが必要です。

OpenAI でかかるもの目安（1回あたり）
記事の文章を書く約20〜30円（記事1本）
サムネイル（見出し画像）を AI で作る約4〜5円（1枚）。写真をサムネにしていない記事で自動で作られます。オフにもできます
Webで調べて書く（最初はオフ）約3〜11円（記事1本）
記事の中に AI の挿絵を入れる（最初は0枚）約4〜5円（1枚）
この金額は目安です

ふだんの記事1本（文章＋サムネ）で約25〜35円が目安です。 ただし文章の金額は、実際の記事で測りきれていない見込みの値です （調べる・画像は試しに動かしたときの実測です）。記事の長さや修正の回数で前後します。 正確な額は OpenAI の画面（Usage）でご確認ください。

★自動チャージ（Auto recharge）はオフのままにしてください。 前払いの残高が、使いすぎの歯止めになります。

LINE の200通を使い切ったら

記事のプレビューや完成のお知らせが届かなくなります。 ただし勝手に料金が発生することはありません。 無料プランは、上限を超えて送れない仕組みだからです。 あなたの発言への返信は無料なので、そちらは今までどおり届きます。

使い切ったときは、システムが LINE でお知らせします。取れる道は3つです。

  1. 来月まで待つ（翌月1日にまた200通に戻ります）
  2. note の画面から直接投稿する （記事の全文は LINE の「過去記事一覧」から出せます）
  3. 月額プランに上げる（ライトプラン 月5,000円・税別で5,000通）

目安として、記事1本あたり通知は1〜2通です。修正を重ねるほど増えます。 多くの場合、月5,000円を払うより、当たった月だけ 2 で済ませるほうが現実的です。

この手順で集める3つの値

あちこちのサイトから少しずつ集めることになります。最後に配備の画面でまとめて貼るので、 見つけたらメモ帳などに控えておいてください。

LINE_CHANNEL_SECRET LINE Developers → チャネル基本設定
LINE_CHANNEL_ACCESS_TOKEN LINE Developers → Messaging API設定（長期）
OPENAI_API_KEY OpenAI の開発者向け画面（sk- で始まる）

つまずいたら

症状原因と対処
配備の画面で「Wrangler 構成ファイルの解析中に問題が発生しました」 URL の打ち間違いか、一時的な不調です。URLを貼り直して開き直してください
配備で この名前のプロジェクトはすでに存在します 前に作ったものが残っています。別の名前を付けるのがいちばん早いです （消しても、名前が空くまで少し時間がかかります）
配備の途中で no such table: articles 前に失敗したデータベースが再利用されています。 データベース名を別のものに変えてやり直してください
設定画面で「届くかの確認」に × が付く 配備直後はアドレスが行き渡るまで数分かかります。2〜3分おいてもう一度実行してください
設定画面が「コードが必要です」と言う 一度セットアップが終わっている環境です。LINE で 「セットアップ」 と送るとコードが届きます
拡張が「サーバーに接続できませんでした」 接続先が違います。拡張の 「▼ 接続先の設定」 に、あなたのURLを貼って「保存する」
間違えて別の人が持ち主になった 設定画面（/setup）の 「持ち主の登録をやめる」 を押し、 そのあとあなたが最初にLINE へ送ってください
LINE に「OpenAI の残高または利用上限に達しています」と返ってくる 前払いの残高が足りません。03 のお支払いの画面で 「Add to credit balance」から買い足してください（最低5ドル）。 書きかけの内容は残っているので、買い足したらもう一度お試しください
「OpenAI の API キーが無効です」「正しく登録されていません」 キーの貼り間違いか、キーを消した可能性があります。03 で新しいキーを作り、 Cloudflare の画面 → お使いの Worker → 設定 → 変数とシークレット の OPENAI_API_KEY を貼り直してください（sk- で始まり、前後に空白が無いこと）
「組織の認証（Organization Verification）が必要」と出る OpenAI 側の手続きです。03 の「組織の認証を求められたら」のとおり手続きしてください。 済むまでは画像が作られませんが、記事の文章は届きます
「OpenAI のモデルが使えません」と出る 使えないときは自動で別のモデルに切り替えます。それでも出る場合は、 OpenAI 側の変更でシステムの更新が必要なことがあります。提供元にご連絡ください
/health の llm が none OpenAI のキーが登録されていません。Cloudflare の画面 → お使いの Worker → 設定 → 変数とシークレット で OPENAI_API_KEY を登録してください
記事の最後に「参考にした情報」が付かない／「与えた情報だけで書きました」と出る 「AI設定」の調べ方が「与えた情報だけ」になっているか、調べたけれど確かな出典が見つからなかったためです。 調べられなかったときは、プレビューの「もう一度調べる」で調べ直せます
送っても何も返ってこない 応答設定の Webhook がオフ。01 の応答設定を見直してください
定型文と AI の返信が両方来る 応答メッセージがオン。オフにしてください
メニューが出ない トークを一度閉じて開き直す。それでも出なければ、設定画面（/setup）でもう一度実行してください
連携コードが違うと言われる 15分で切れます。LINE でもう一度「note連携」と送って新しいコードで
メール認証が完了していません note の確認メールを開いていません。02 に戻ってください
公開を押したのに投稿されない note のログインが切れている可能性があります。LINE で「連携状況」を確認してください
拡張のアイコンに「!」が出る 連携が切れています。LINE で「note連携」からやり直してください
記事を消したい note の画面から消してください（LINE に削除ボタンはありません）。 消せば LINE の一覧からも自動で消えます。 書き直したいだけなら、一覧から開いて「修正する」で同じ URL のまま直せます
GitHub から「自動更新が止まっています」というメールが届いた システムはこれまでどおり動いています（何も変えていません）。 メールの中の Issue の URL を、提供元にお伝えください
いまの状態を知りたい LINE で「連携状況」。技術的には /health を開くと全項目が見えます

結局、人の手が要るのはこれだけ

黒い画面（ターミナル）は一度も出てきません。 それでも自動化できない作業が残ります。どのサービスも 「アカウントを作る」「本人としてログインする」「鍵を発行する」の3つには 窓口を用意していないからです。意図的にそうしている部分なので、迂回はしません。

人がやることいつ
5つのアカウントを作る（LINE・note・OpenAI・Cloudflare・GitHub）初回のみ
OpenAI の残高を買い足す残高が減ったとき
鍵を3つ、配備の画面に貼る初回のみ
自動更新のファイルを1つ作る（GitHub の画面で1行貼る）初回のみ
LINE の応答メッセージをオフにする初回のみ
note にログインして、拡張のボタンを押す初回＋月1回ほど

日常的に発生するのは、note へのログインのし直しと、 OpenAI の残高の買い足しの2つだけです。どちらも数手で終わります。
